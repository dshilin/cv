# Реестр критериев и связей

Это начальный указатель: перенесены все 8 критериев приёмки SPEC-001,
12 критериев SPEC-002 и 6 архитектурных инвариантов SPEC-003.
Остальные функциональные и нефункциональные требования остаются в исходных
документах: их полный разбор на атомарные требования ещё не выполнен.
Реестр не заменяет ТЗ и не является утверждением их содержания.

ID закреплены за исходными критериями и не меняются при перестановке строк.
При уточнении сначала меняется источник по разрешённому решению, затем
этот указатель. Связанные расхождения смотри в
[реестре вопросов](../governance/open-questions.md).

Для строк без связи: задача и реализация не созданы, проверка не выполнена.
При реализации замени эти значения реальными ссылками и результатами;
не считай наличие строки доказательством выполнения требования.
