## Будущие экспорты

Из корня запускается `python scripts/build_architecture_tz.py` при наличии
`python-docx`. Файл получает имя с версией и временем в `docs/exports/`.
Источник истины — соответствующая Markdown-редакция. Экспортный скрипт
исторически поддерживает только простые заголовки, списки, таблицы и блоки
кода; перед передачей Word проверь отображение и ссылки. Сам запуск
генератора не подтверждает качество верстки.
