# Состояние проекта

## Выполнено 2026-09-24

- Выполнен этап 1 [PLAN-001](superpowers/plans/2026-09-24-cv-maker-web-interface-plan.md):
  создано приложение `frontend/` на React, TypeScript и Vite с семью
  маршрутами, навигацией и тремя временными индикаторами состояния.
  Предметные экраны и расчёт состояний относятся к следующим этапам.
- Согласована концепция веб-интерфейса CV Maker: сначала универсальный
  подтверждённый профиль, затем сервисы поиска, поисковые профили, вакансии и
  только в конце явное подтверждение отклика.
- Подготовлен черновик [SPEC-004](superpowers/specs/2026-09-24-cv-maker-web-interface-design.md)
  с необходимым и достаточным критерием готовности профиля и критериями
  проверки UX. Письменная спецификация ожидает review пользователя.

- Найдены три Markdown-источника, Word-копия и её генератор.
- Исходные Markdown-тексты перенесены в единый каталог и приведены к UTF-8/LF.
- Добавлены реквизиты, реестр, инструкции агента, рабочий процесс и шаблоны.
- Архивная Word-копия сверена с исходным Markdown: основной текст и таблицы
  совпадают, дополнительных комментариев и отслеживаемых правок нет.
- Продуктовые расхождения зарегистрированы как Q-001–Q-007.
- Исходные критерии и инварианты связаны с реестром REQ-001–REQ-026.
- Генератор перенесён в scripts; источник и каталог экспорта обновлены.
- Git-репозиторий инициализирован 2026-09-24 на ветке `main`; первый коммит
  документации: `c9fea3f` (`docs: initial project documentation`). Удалённый
  репозиторий ещё не создан из-за отсутствия доступного GitHub-коннектора или
  GitHub CLI в текущей среде.

## Состояние продукта

Есть каркас веб-приложения, тест оболочки и чистая модель готовности профиля
(этап 2 PLAN-001). Предметные экраны, подключение модели к маршрутам,
хранение данных и отправка откликов пока не реализованы. Удалённый
GitHub-репозиторий пока не настроен. ТЗ содержат планы и предложения; их
продуктовое утверждение не подтверждено. Реестр критериев не означает
выполненную реализацию.

## Следующий шаг

Для локального запуска каркаса: `cd frontend`, `npm ci`, `npm run dev`.
Проверки: `npm test` и `npm run build`. Следующий этап PLAN-001 — редактор
профиля и проверка извлечённых фактов.

Для задачи разработки прочитать [открытые вопросы](governance/open-questions.md)
и определить, какие из них блокируют выбранный этап. Сначала требуется
согласовать роль CV Maker и границы интеграции (Q-001) для генерации,
схему фактов (Q-004–Q-005) для модели данных. Наличие вопросов не мешает
выполнять независимую подготовку в рамках нового поручения.

Автоматическая отправка откликов, подключение внешних аккаунтов и создание
приложения не выполнялись в задаче организации документации.
