# Состояние проекта

## Выполнено 2026-09-24

- Найдены три Markdown-источника, Word-копия и её генератор.
- Исходные Markdown-тексты перенесены в единый каталог и приведены к UTF-8/LF.
- Добавлены реквизиты, реестр, инструкции агента, рабочий процесс и шаблоны.
- Архивная Word-копия сверена с исходным Markdown: основной текст и таблицы
  совпадают, дополнительных комментариев и отслеживаемых правок нет.
- Продуктовые расхождения зарегистрированы как Q-001–Q-007.
- Исходные критерии и инварианты связаны с реестром REQ-001–REQ-026.
- Генератор перенесён в scripts; источник и каталог экспорта обновлены.
- Git-репозиторий инициализирован 2026-09-24 на ветке `main`; первый коммит
  документации: `c9fea3f` (`docs: initial project documentation`). Удалённый
  репозиторий ещё не создан из-за отсутствия доступного GitHub-коннектора или
  GitHub CLI в текущей среде.

## Проверки текущего изменения

- `python scripts/check_docs.py` — успешно: 11 зарегистрированных
  документов, 13 Markdown-файлов, 78 локальных ссылок. В текущей среде
  команда выполнена через доступный абсолютный путь к Python 3.
- Исходное содержание трёх Markdown-файлов сверено с контрольными суммами
  до нормализации окончаний строк: потерь и смысловых правок нет.
- SHA-256 архивной Word-копии совпадает с исходным значением.
- Синтаксис двух Python-скриптов проверен через `ast.parse`.
- Проверяющий скрипт отклоняет битую ссылку, отсутствие обязательного
  реквизита и CRLF; отрицательные случаи проверены в памяти без изменения
  рабочих документов.
- Генератор Word проверен в памяти: читает новый путь, исключает служебные
  реквизиты и навигацию, создаёт корректный DOCX-пакет. Новая Word-выгрузка
  не создавалась; визуальная приёмка её верстки не выполнялась.

Эти результаты относятся к организации документации, а не к тестированию
продукта или актуальности внешних API.
