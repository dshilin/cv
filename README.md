# CV — проект подготовки резюме и поиска работы

Все рабочие ТЗ, архитектурные документы и правила находятся в
[едином реестре документации](docs/README.md).

Агент начинает работу с [AGENTS.md](AGENTS.md). Текущее состояние и
следующие шаги описаны в [журнале проекта](docs/progress.md).

Документы описывают планируемый продукт и границы текущего MVP. Приложение
можно запустить одной командой через Docker Compose:

```powershell
docker compose up --build
```

После запуска откройте [http://localhost:8080](http://localhost:8080). Compose
доступен только с этой машины и использует development identity без
аутентификации; не публикуйте его на общем или публичном сервере.
Подробности локального запуска backend находятся в
[инструкции эксплуатации](docs/operations/backend.md).

Проверка документации из корня проекта (Python 3, без сторонних библиотек):

```shell
python scripts/check_docs.py
```

Для отдельной выгрузки архитектуры в Word предусмотрен
`scripts/build_architecture_tz.py` (требуется `python-docx`). Выгрузки
не заменяют Markdown; порядок работы описан в реестре.
